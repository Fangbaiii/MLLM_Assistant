# Qwen3-VL-Doc-LoRA 模型卡片

## 基本信息

- 模型名称：`Qwen3-VL-Doc-LoRA`
- 基座模型：`Qwen3-VL-8B-Instruct`
- 发布检查点：`checkpoint-388`
- 任务定位：中文多模态文档理解、OCR 问答、复合文档区分、文档/图片多轮追问

## 这次微调带来的核心收益

相对未微调的 Base，`Qwen3-VL-Doc-LoRA` 的提升主要集中在项目真正关心的文档类任务，而不只是回答风格变化。

- 三模式回归集 `char-F1` 从 `0.2325` 提升到 `0.6257`，提升 `169.15%`
- 文档修复专项集 `char-F1` 从 `0.3143` 提升到 `0.7115`，提升 `126.37%`
- 综合能力集 `char-F1` 从 `0.1733` 提升到 `0.2233`，提升 `28.84%`

这些增益主要体现在：

- 更擅长从长 OCR 文本里抽取主题、事实和关键依据，而不是机械复述材料
- 更擅长区分多份 OCR / 复合文档，减少把不同材料混在一起的情况
- 更擅长在多轮追问里补充“新增信息”，而不是重复上一轮答案
- 在文档、图表和图片解释任务上，回答更贴近证据，结构也更稳定

## 相对 Base 的具体优势

### 1. 文档与 OCR 任务更稳

Base 在长 OCR、复合材料和文档追问任务上，容易出现两类问题：

- 抓不住用户真正要的信息，只做宽泛概括
- 能读到材料内容，但回答组织不稳定，证据边界不清晰

`Qwen3-VL-Doc-LoRA` 对这些场景做了针对性修复，更偏向：

- 先给结论，再给依据
- 只抽取与问题相关的 OCR 信息
- 遇到多份材料时按材料分别作答，减少串扰

### 2. 多轮增量信息更好

在图片和文档多轮任务中，Base 更容易重复前文，或者忽略“这一轮到底新增问了什么”。

`Qwen3-VL-Doc-LoRA` 的优势是：

- 对历史约束更敏感
- 更容易补充上一轮未提到的细节
- 在继续解释、核对、比较时更少原句重说

### 3. 输出质量更接近任务需求

Base 并不总是“不会答”，但经常“不够贴题”。`Qwen3-VL-Doc-LoRA` 相对更贴近项目里的实际使用目标：

- 简短问题保持简洁
- 需要展开时给出足够依据
- 更少无关扩写和材料外补写

## 训练与评测范围

该模型面向以下重点场景优化：

- OCR 单文档理解
- 复合 OCR 材料对比
- OCR 多轮追问
- 图片分析与图片多轮补充
- 文档、图表中的字段、数字与依据提取

评测指标以项目内统一评测器为准，重点关注：

- `char-F1`
- 长度合规率
- `early EOS`
- `repeat 4-gram`
- 多轮上下文关键词召回

## 已知边界

这个检查点的优势集中在中文文档、多模态证据和任务型追问。对于超出主要训练范围的开放式长文创作或跨领域泛化任务，仍应单独评估，不宜直接从本卡片外推。
